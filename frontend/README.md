# FirstLine Frontend

React and Tailwind CSS frontend for the LinkedIn icebreaker backend.

## Run locally

Start the backend on port `8000`, then:

```bash
npm install
npm run dev
```

The app opens at `http://localhost:5173`.

To use another backend URL, copy `.env.example` to `.env` and change
`VITE_API_URL`.

## Production build

```bash
npm run build
```
